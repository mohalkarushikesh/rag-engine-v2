- Boto3 is the official **AWS SDK** for Python that allows developers to **create, configure, and manage Amazon Web Services (AWS)** resources like Amazon S3 
and Amazon EC2 directly from Python scripts.

- The Keyword Arm: Uses traditional **lexical matching** to look for exact word overlaps between the query and the documents.

- An ONNX (Open Neural Network Exchange) model is used to **store, transfer, and run machine learning and deep learning models** across different AI frameworks and hardware platforms. 

- AWS App Runner is a fully managed, container-native **Platform-as-a-Service (PaaS).** It allows developers **to quickly build, deploy, and run containerized web applications** and API services without managing underlying servers, orchestrators (like Kubernetes), build pipelines, or load balancers.
    - **Powered by AWS Fargate infrastructure**, it acts as a "hands-off" cloud runtime environment where you simply point to your code or container image, and AWS handles the rest.

- Ingest documents — **Load, clean, and split source documents into chunks.**

- Sentence Transformer is a model that **generates fixed-length vector representations (embeddings) for sentences or longer pieces of text**, unlike traditional models that focus on word-level embeddings. These representations are particularly useful in tasks where understanding the context or meaning of an entire sentence is required.
